# 바탕화면 키우기 — Desktop Companion

픽셀 캐릭터가 바탕화면 위에서 살아가는 데스크톱 컴패니언. 기획서는 리포 루트의
`Desktop_Companion_Game_Plan.md` 참고.

## 현재 상태: Phase 4 진행 중 — 화면 엿보기

구현된 것:

- 투명 · 항상 위 · **클릭통과** 오버레이 창 (캐릭터의 불투명 픽셀 위에서만 마우스 이벤트 수신 — per-pixel hit-test)
- 플레이스홀더 픽셀 캐릭터 (ASCII 맵 → 캔버스 베이크, 걷기/달리기/낮잠/지침/허둥대기 애니메이션)
- 행동 FSM: **화면 전체 2D 자유 배회**(wander) ⇄ 쉬기(idle), 마우스 따라오기(걷기→멀면 달리기→스태미나 소진 시 지침), 낮잠, 기다려
- **집어 옮기기**: 클릭만으로는 잡히지 않고, 누른 채 8px 이상 끌어야 집힘 — 머리를 잡힌 채 공중에 떠서 다리를 허둥대며 살랑살랑 흔들림 (`!?`) → 놓으면 어리둥절(`…`)하다가 일상 복귀
- **이모트 의사표현**: 말풍선/텍스트 없이 `!` `?` `…` `♪` `Zz…` `;;` 같은 심볼이 머리 위에 떠올랐다 사라짐
- **스탯 시스템**: 기운·허기·졸림·기분. 배고프면 `~?` 조르기, 졸리면(밤에 더 빨리) 스스로 낮잠 → 다 자면 기상. 우클릭 메뉴 상단에 게이지 표시
- **창 쳐다보기 (뒤돌아보기)**: 활성 창이 바뀌면 확률적으로 그 창 쪽으로 걸어가 **등을 보이고 서서** 같이 구경 (`?`) — **Windows·macOS 둘 다 지원**
- **사용자 감지 리액션**: 키보드 타이핑(어떤 키인지는 수집 안 함 — 입력 유무만)·커서 활동을 감지해 Co-work 발동, 90초 이상 자리 비우면 두리번거리며 `?` — **Windows·macOS 둘 다 지원**, 추가 권한 요청 없음
- **1인용 소파 (가구)**: 캐릭터 우클릭 → "소파 꺼내기". 소파가 있으면 **소파 반경 240px 안에서만** 배회하고 종종 소파에 앉아 쉼 — 돌아다니는 게 부담스러운 사용자용. 소파는 드래그로 위치 이동(저장됨), 구경/합류 외출도 안 함
- **옷장 (Phase 2)**: 우클릭 → "옷장 열기" — **모양 파츠**(머리스타일 4종·눈 3종·입 3종·상의 3종, ◀▶로 선택) + **색**(피부/머리/상의/하의 견본)을 즉시 반영, 저장됨. 파츠는 레이어 합성(베이스→상의→머리→눈→입)으로 렌더링
- **전체화면 앱 자동 숨김** (Windows): 유튜브 전체화면·게임 등 전면 창이 모니터를 꽉 채우면 캐릭터가 숨고, 벗어나면 다시 나타남 (상주 PowerShell 워처로 Win32 폴링 — 네이티브 모듈 없음). macOS는 스페이스 분리로 자동 처리
- **같이 일하기 (Co-work)**: 사용자가 한동안 계속 작업(커서 활동)하면 활성 창 옆자리로 와서 무릎에 노트북을 놓고 같이 타이핑 ("나도 일할래!"). 손을 놓으면 "쉬는 거야?" 하고 일어나고, 한 세션 끝나면 "오늘도 열일!" 후 잠시 쉼 — **Windows·macOS 둘 다 지원**
- **멀티플레이 (Phase 3)**: 캐릭터 우클릭 → "친구들…" — 방 만들기(6자리 초대 코드) / 코드로 참여, **최대 4명**. 친구 캐릭터가 각자의 커스터마이징 그대로 내 바탕화면에 나타나 돌아다님 (행동 intent + 정규화 좌표 동기화 → 해상도 달라도 OK, 부드러운 보간). 근접하면 `♪` 인사. **네트워크·화면 엿보기는 순수 WebSocket/WebRTC(Electron 내장)라 OS 무관 — Windows·macOS 크로스플랫폼 룸 참여가 가능함**
- **말풍선 채팅**: `Ctrl+Shift+Space` 또는 우클릭 메뉴 → 채팅. 캐릭터 머리 위 픽셀 말풍선(시간 지나면 사라짐), 친구 캐릭터 클릭 → 대화 기록 패널. 서버 측 도배 방지
- **화면 엿보기 (Phase 4)**: 친구 캐릭터 **우클릭 → "화면 보여줘 요청"** → 상대에게 승인 패널 → 허용하면 그때부터 **친구 캐릭터에 마우스를 올린 동안만** 캐릭터 위 픽셀 액자에 상대 화면이 실시간(960×540·8fps, WebRTC P2P)으로 보임. 프라이버시 장치: 공유 중 캐릭터에 `●`/`LIVE` 상시 표시, 시청 시작 시 송신자에게 알림, hover를 벗어나면 송출 자체가 일시정지, 송신자는 메뉴에서 언제든 전체 중지, 시청자도 "그만 보기" 가능. 승인은 방 세션 단위(나가면 소멸)
- **트레이 설정**: 캐릭터 크기(작게 2x/보통 3x), 활동성(아주 차분함/보통/활발함), **모니터 이동**(멀티 모니터), 부팅 시 자동 시작. 설정은 settings.json에 저장
- 우클릭 컨텍스트 메뉴 (따라와/그만 따라와, 낮잠, 기다려, 간식 주기, 쓰다듬기, 숨기기, 종료)
- 좌클릭: 낮잠 중이면 깨우기, 아니면 쓰다듬기(하트)
- 적응형 커서 폴링 (따라다니거나 집혀 있을 때 30Hz, 평소 10Hz — CPU 예산)

기본값: 크기 **작게(2x)**, 활동성 **보통** (예전 '차분함'이 지금의 '활발함').

### 파츠 매니페스트 = 모드 포맷 (기획서 §8)

`src/engine/parts.ts`의 `PartsPack` 스키마가 그대로 Workshop 파츠 팩의
manifest.json 포맷이다: `{ name, author, version, parts: [{ id, slot, name,
map: { y0, rows }, back? }] }`. 엔진은 내장 팩과 모드 팩을 구분하지 않으며
(`packs[]`에 추가만 하면 옷장에 나타남), 파츠 맵 규격 검증 테스트
(`tests/parts.test.ts`)가 업로드 린트의 원형이다. 다음 단계: 폴더 스캔
로더(핫리로드) + PNG 파츠 지원.

## 실행 (Windows / macOS)

Windows: `run.bat` 더블클릭 — 설치·빌드 후 앱을 **분리 실행하고 창은 저절로
닫힌다** (cmd 창을 켜둘 필요 없음). 문제가 있을 땐 `debug.bat`(창 유지 +
전체 로그).

```bash
cd desktop-companion
npm install
npm start           # 개발 모드
npm run dist        # Windows 설치 파일(.exe) 빌드 → release/ (Windows에서 실행)
npm run dist:mac    # macOS 설치 파일(.dmg) 빌드 → release/ (macOS에서 실행)
```

`npm run dist`/`dist:mac`로 만든 설치 파일을 쓰면 Node.js·run.bat 없이 일반
프로그램처럼 설치/실행되고 시작 메뉴·Launchpad에도 등록된다 (배포·Steam 빌드의
기반).

### 미리 빌드된 설치 파일 받기 (공유용)

코드가 푸시될 때마다 GitHub Actions가 **Windows(.exe)와 macOS(.dmg) 설치 파일을
둘 다** 빌드해서 하나의 릴리스에 올려준다 — 각자 빌드할 필요 없이 아래에서 바로
받으면 됨:

**https://github.com/erie-pixel/ClaudeBusiness/releases**

macOS는 처음 실행 시 "화면 위에 표시"·화면 녹화(화면 엿보기 기능용) 관련 권한을
요구할 수 있음. 종료는 캐릭터 우클릭 → 종료, 또는 트레이 아이콘.

### macOS 문제 해결

- **코드 서명이 없는 개발 빌드**라 Gatekeeper가 막을 수 있음:
  - "확인되지 않은 개발자" 경고 → Finder에서 앱 **우클릭(또는 Control+클릭) →
    열기** → 다시 "열기" 확인.
  - 그래도 **"손상되었습니다. 이동 휴지통으로 이동"**이 뜨면(다운로드 시 붙는
    격리 플래그 때문) 터미널에서:
    ```bash
    xattr -cr "/Applications/Desktop Companion.app"
    ```
    실행 후 다시 열면 된다. 정식 출시(Steam) 시에는 코드 서명·공증을 거쳐
    이 과정이 필요 없어짐 (기획서 §6 macOS 코드사이닝 항목).
  - 앱이 Intel/Apple Silicon 어느 Mac에서든 동작하는 **universal 빌드**임.

### macOS 화면 워처 (native/mac-watcher.swift)

창 쳐다보기·같이 일하기·방치 감지는 Windows의 PowerShell 워처와 대응하는
작은 Swift 헬퍼(`native/mac-watcher.swift`)로 구현되어 있고, **추가 권한
요청이 없다**:

- 활성 창 위치는 `CGWindowListCopyWindowInfo`로 읽는데, 창 **제목**은 요청하지
  않으므로 화면 기록(Screen Recording) 권한이 필요 없다 (제목만 그 권한이
  걸려 있고 위치·소유 프로세스는 공개 정보).
- 유휴 시간은 `CGEventSource`의 시스템 카운터(화면보호기가 쓰는 것과 동일)를
  읽을 뿐이라 손쉬운 사용(Accessibility)·입력 모니터링 권한이 필요 없다.
- 헬퍼가 없거나 죽어도(구버전 macOS, 컴파일 실패 등) 이 세 행동만 조용히
  비활성화되고 앱은 정상 동작한다.

배포되는 DMG에는 CI(macos-latest, GitHub Actions)에서 `swiftc`로 Intel/Apple
Silicon 양쪽용을 각각 컴파일한 뒤 `lipo`로 합친 **universal 바이너리**가
`Contents/Resources/mac-watcher`로 내장되어 있어 사용자는 Xcode 없이도 바로
쓸 수 있다. 로컬 개발 모드(`npm start`)에서 이 기능을 켜려면 Xcode Command
Line Tools가 설치된 Mac에서 직접 컴파일해야 한다:

```bash
swiftc -O native/mac-watcher.swift -o build/mac-watcher
```

### Windows 문제 해결

- **run.bat 창이 뜨자마자 꺼짐**: GitHub ZIP으로 받은 파일은 Windows가
  "인터넷에서 받은 파일"(Mark-of-the-Web)로 차단할 수 있음 —
  `run.bat` 우클릭 → 속성 → 하단 **차단 해제** 체크 → 확인. 또는 ZIP 파일
  자체를 압축 해제 전에 차단 해제하면 내용물 전체에 적용됨.
- **OneDrive 폴더(바탕 화면 포함)는 피할 것**: node_modules 동기화가 설치를
  깨뜨림 — `C:\officebud` 같은 짧은 영문 경로 권장.
- 배치 스크립트 수정 시 **if/for 블록 안 echo에는 괄호 금지** — cmd가 블록
  구분자로 세어 파싱 단계에서 스크립트 전체가 죽음 (대시로 대체).

## Phase 0 검증 체크리스트 (실물 OS에서 확인해야 하는 것)

- [ ] 캐릭터가 없는 영역에서 클릭/드래그가 아래 앱으로 100% 통과되는가
- [ ] 캐릭터 위에서만 커서가 pointer로 바뀌고 클릭/우클릭이 먹는가
- [ ] 유튜브 전체화면·게임 실행 시 캐릭터가 자동으로 숨고, 벗어나면 다시 나타나는가
- [ ] 우클릭 메뉴가 열린 동안 메뉴 클릭이 정상 동작하는가
- [ ] 따라오기 → 멀리 도망 → 달리기 → 지침 → 회복 루프가 자연스러운가
- [ ] 유휴 시 CPU 점유율 (목표 < 1~2%)

## 멀티플레이 서버 (relay)

**서버는 앱에 내장되어 있다** — "친구들…" 패널에서 "방 만들기"를 누르면 내
PC가 자동으로 호스트가 되고(포트 8787), 패널에 친구가 입력할 접속 주소가
표시된다. 별도 cmd 창이나 `npm run server`가 필요 없다.

```bash
npm run server      # (선택) 상시 서버를 따로 운영할 때만 — VPS 등
```

서버는 룸·presence·중계만 담당하는 얇은 relay (`server/relay.mjs`).
빈 방은 2분간 보존되어 순간 끊김 후 재접속이 가능하고, 클라이언트는 끊기면
같은 방으로 최대 5회 자동 재접속을 시도한다.

정식(Steam) 버전에서는 이 relay가 Steamworks의 P2P 네트워킹(Steam Datagram
Relay)으로 대체되어, IP/터널 없이 친구 목록에서 초대 클릭만으로 연결된다
(기획서 §7).

### 친구와 연결하는 법 (무료, 계정 거의 불필요)

호스트가 앱에서 "방 만들기"를 누른 뒤(서버 자동 시작), 패널에 표시된 주소
중 상황에 맞는 것을 코드와 함께 공유:

1. **Tailscale (권장)** — 둘 다 https://tailscale.com 설치(무료) 후 같은
   계정/네트워크로 로그인. 서버 켠 사람의 Tailscale IP(예: `100.x.y.z`)로
   친구가 `ws://100.x.y.z:8787` 입력. 설정 한 번이면 계속 사용 가능.
2. **cloudflared 터널 (계정 불필요)** — 서버 켠 사람이
   `cloudflared tunnel --url http://localhost:8787` 실행 → 나오는
   `https://xxx.trycloudflare.com` 주소를 `wss://xxx.trycloudflare.com`으로
   바꿔 친구에게 공유. 실행할 때마다 주소가 바뀌는 임시 터널.
3. **같은 공유기(같은 집/사무실)** — 서버 PC의 내부 IP로 `ws://192.168.x.x:8787`.

(친구는 "참여 서버" 칸에 받은 주소를 넣고 코드로 참여)

## 설계 노트

- Phase 0 렌더링은 Canvas 2D. 파츠 레이어 합성 + 팔레트 스왑이 들어오는
  Phase 2에서 PixiJS(WebGL)로 교체 예정 — 엔진 로직은 렌더러와 분리되어 있어
  교체 비용이 작다.
- 커서 좌표는 `forward: true`의 mousemove 대신 메인 프로세스 폴링으로 일원화
  (플랫폼별 forward 편차 회피, 창 밖 커서도 추적 가능).
